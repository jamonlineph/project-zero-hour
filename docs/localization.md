# Localization

Project Zero Hour uses gettext with **English text as the message id**: what a button says in English is the key its translations are filed under.

## How it works

- Buttons and labels with fixed text translate on their own (Godot's auto-translate).
- Text built in code (`"Credits: %d" % n`) goes through `Loc.t()` before formatting: `Loc.t("Credits: %d") % n`. Names from the game data (units, buildings, powers, maps, factions) are passed through `Loc.t()` where they are shown.
- The sim never sees translated text: everything in `game/src/sim` stays in ids.
- The player picks the language in Settings (Language: device language, English, Español). "Device language" follows the phone or computer.

## Files

| File | What |
|---|---|
| `game/locale/messages.pot` | The template: every text the player sees, generated by `python3 tools/extract_strings.py` from the UI scripts and the game data. `check_repo` fails when it is out of date |
| `tools/i18n/<code>.py` | A language's translations, as a Python table `T = {english: translation}`. Edit this |
| `game/locale/<code>.po` | Built from the table and the template by `python3 tools/i18n/build_po.py <code>` (also checked by `check_repo`); listed in `project.godot` under `internationalization/locale/translations` |

Texts missing from a table stay in English, so a partial translation is fine.

## Adding a language

1. Copy `tools/i18n/es.py` to `tools/i18n/<code>.py` (ISO 639-1 code, for example `fil` or `de`) and translate the values. Keep `%s`, `%d`, `%%`, `\n` and `[b]` tags exactly as they are.
2. Run `python3 tools/i18n/build_po.py <code>`.
3. Add `"res://locale/<code>.po"` to `locale/translations` in `game/project.godot`, and the language to `Loc.LANGUAGES` in `game/src/ui/loc.gd`.
4. Run `tools/run_tests.sh` and `python3 tools/check_repo.py`.

Translators who prefer a web tool can work in Weblate on the `.po` files (`messages.pot` is the template). Bring the results back into the table with a small script, or switch a language over to hand-edited `.po` by deleting its table.

## When you add UI text

Write it so the extractor finds it: fixed text in `.text = "..."`, `_button(parent, "...", ...)`, `_cycle("...")`, `_header("...")`, or built text through `Loc.t("...")`. Then run `python3 tools/extract_strings.py` (and `build_po.py` for each language) and commit the updated files.
