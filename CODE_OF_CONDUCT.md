# Code of conduct

This project welcomes everyone who wants to make a good game together.

**Expected:** being respectful and patient, giving feedback about the work rather than the person, assuming good intent, and helping newcomers.

**Not accepted:** harassment, insults, discrimination, sexualized content, doxxing, threats, or sustained disruption. That applies in issues, pull requests, chats and any project space.

**Real-world topics:** the game is set in a fictional 2026 conflict between real nations. Keep discussion about the game. Don't bring real-world hatred toward any nationality, ethnicity or group into project spaces.

**Enforcement:** the project owner (and later the maintainers) can edit or remove content and block participants who break these rules. Report problems privately to the owner via the contact listed on the repository profile.
